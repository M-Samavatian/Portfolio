# Samavatian | محمدحسین سماواتیان

وب‌سایت شخصی و نمونه‌کارهای محمدحسین سماواتیان، توسعه‌یافته با HTML، CSS و JavaScript.

## راه‌اندازی در GitHub Pages
1. فایل‌های **داخل این پوشه** را در ریشه یک ریپازیتوری عمومی GitHub قرار دهید.
2. به **Settings → Pages** بروید.
3. بخش **Build and deployment** را روی **Deploy from a branch**، شاخه `main` و پوشه `/ (root)` تنظیم کنید.
4. آدرس سایت به‌شکل `https://USERNAME.github.io/REPOSITORY/` خواهد بود.

تمام لینک‌های داخلی نسبی هستند و در GitHub Pages با مسیر ریپازیتوری کار می‌کنند.

## شخصی‌سازی
- `js/config.js`: متن‌ها، نمونه‌کارها، اطلاعات تماس
- `contact/contact.js`: شماره، راه‌های ارتباطی و اطلاعات کارت مخاطب
- `contact/qr-generator.html`: تولید کد QR با آدرس **فعلی** صفحه تماس

**توجه:** شماره تلفن و واتساپ موجود در فایل اصلی حفظ شده‌اند. شناسه‌های شبکه‌های اجتماعی وابسته به برند قبلی حذف/مخفی شده‌اند؛ فقط پس از تأیید حساب شخصی، لینک صحیح را درج کنید. آدرس GitHub در تنظیمات روی `m-samavatian` گذاشته شده است؛ صحت مالکیت آن را قبل از انتشار بررسی کنید. پروژه‌های نمونه از نسخه اصلی حفظ شده‌اند؛ مالکیت و رضایت انتشارشان باید تأیید شود.
